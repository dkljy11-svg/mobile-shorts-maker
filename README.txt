모바일 쇼츠 메이커 V6.0

추가 기능
- 맛집 TOP5, 여행 TOP5, 쇼핑 추천, 가성비, 추천·비추천, 랭킹 템플릿
- 템플릿별 첫 제목 카드
- 컷마다 자동 랜덤 모션
- 줌인, 줌아웃, 좌우 이동
- 1~3위 메달 배지
- 컷 단계 표시 점
- CTA 화면 디자인 강화
- 썸네일 PNG 저장
- 컷별 자막과 표시 시간
- 1080×1920 출력
- 영상 공유와 YouTube 열기

업데이트
1. 기존 GitHub mobile-shorts-maker 저장소
2. Add file > Upload files
3. 압축을 푼 index.html, manifest.webmanifest, sw.js, README.txt 업로드
4. Commit changes
5. 1~2분 후 기존 주소 새로고침
6. 예전 화면이면 Ctrl+F5 또는 모바일 브라우저 캐시 삭제

주의
- 출력 형식은 브라우저가 지원하는 MP4 또는 WebM입니다.
- 아이폰 Safari는 기기와 버전에 따라 영상 생성 기능이 제한될 수 있습니다.
